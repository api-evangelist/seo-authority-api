# SEO Authority API

Domain authority and content intelligence API from ForgeMesh Labs, computed from the Common Crawl hyperlink graph rather than scraped Google data. Ten REST endpoints (domain authority, keyword opportunity, competitor gap, content briefs, on-page scoring, site audit, internal-link suggestions) accessed via x402 pay-per-call micropayments in USDC on Base — no accounts or API keys.

## APIs

- **SEO Authority API** — REST API with ten versioned /v1 endpoints for domain authority, keyword opportunity, competitor gap, content briefs, on-page SEO scoring, site audit, and internal-link opportunities. Accessed via x402 pay-per-call (USDC on Base); OpenAPI contract advertised. (`https://seo.forgemesh.io`)

An open-source MCP server (@forgemeshlabs/seo-authority-mcp, npm + Docker) wraps all ten routes plus a free get_seo_capabilities tool, but it is LOCAL/stdio-run (Claude Desktop config), not a hosted remote MCP endpoint — hence not cataloged as an MCPServer property. agent_native=true is set on the basis of the advertised (though unverified) llms.txt.
